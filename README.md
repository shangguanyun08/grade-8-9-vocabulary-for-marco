# Grade 8–9 Vocabulary for Marco

A zero-build GitHub Pages study site made from Zozeck's complete Grade 8–9 list.

- 2,410 captured source entries across 25 chapters
- 1,920 unique words and phrases after exact-spelling deduplication
- fixed easy-to-hard ranking based on general English frequency
- Grade 8 and Grade 9 labels derived from the ranking (ranks 1–960 and 961–1,920)
- search, chapter filters, status filters, sorting, and browser-saved checklist progress

Open `index.html` through a local web server or enable GitHub Pages from the repository's `main` branch.

The captured source is in `data/zozeck-grade-8-9-raw.json`. Run `python scripts/compile_word_list.py` to rebuild `words.json`; install `wordfreq` first when you want to recalculate the frequency scores.
